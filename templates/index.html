HA Container Manager

DRBD + Quadlet + Pacemaker 기반 RHEL9 고가용성 컨테이너 클러스터 설정 도우미

설정 워크플로
1단계: DRBD 설정

클러스터 노드 정보를 입력하여 DRBD .res 파일을 생성하고 Ansible로 /etc/drbd.d/에 배포합니다.

DRBD 설정 시작
2단계: Quadlet 변환

실행 중인 Podman 컨테이너를 분석하여 Quadlet 유닛 파일 (.container, .pod, .volume)로 변환합니다.

Quadlet 변환 시작
3단계: Pacemaker 설정

DRBD Promotable Clone 리소스와 Quadlet Systemd 리소스를 Pacemaker에 등록하고 pcs 스크립트를 생성합니다.

Pacemaker 설정 시작
전제 조건 (AlmaLinux9 / RHEL9)
필수 패키지
# ELRepo 저장소 활성화
dnf install -y elrepo-release
dnf config-manager --enable elrepo

# DRBD 패키지 설치
dnf install -y drbd9x-utils kmod-drbd9x

# Pacemaker / Corosync
dnf install -y pacemaker pcs corosync

# Podman
dnf install -y podman
네트워크 구성
  • 클러스터 노드 간 전용 네트워크 인터페이스 권장
  • DRBD 동기화용 포트 (기본 7789) 방화벽 허용
  • IPVLAN 컨테이너 네트워크용 호스트 NIC 설정
  • corosync 통신 포트 (5404, 5405 UDP) 허용
Ansible 관리 서버
  • 이 웹 서버에서 SSH 키 기반 접근 가능
  • Ansible 설치 필요: pip install ansible
아키텍처 개요

이 도구는 2-노드 HA 클러스터를 구성합니다. DRBD로 블록 스토리지를 Active/Passive 방식으로 복제하고, Quadlet을 통해 systemd가 Podman 컨테이너를 서비스로 관리합니다. Pacemaker는 DRBD Promoted 노드에서만 컨테이너가 실행되도록 제약조건을 관리합니다.

[Node 1] DRBD Primary ← Promoted → Quadlet Container (IPVLAN)
            ↕ DRBD Sync
[Node 2] DRBD Secondary ← Standby
