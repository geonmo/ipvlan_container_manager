IPVLAN Container Manager

A configuration helper for DRBD + Quadlet + Pacemaker high-availability container clusters on RHEL9

Workflow
Step 1: DRBD

Enter your cluster nodes to generate a DRBD .res file and deploy it to /etc/drbd.d/ with Ansible.

Start with DRBD
Step 2: Quadlet

Turn running Podman containers into Quadlet unit files (.container, .pod, .volume).

Start with Quadlet
Step 3: Pacemaker

Register the DRBD promotable clone and the Quadlet systemd resources with Pacemaker and pcs generates the script.

Start with Pacemaker
Prerequisites (AlmaLinux9 / RHEL9)
Required packages
# Enable the ELRepo repository
dnf install -y elrepo-release
dnf config-manager --enable elrepo

# Install the DRBD packages
dnf install -y drbd9x-utils kmod-drbd9x

# Pacemaker / Corosync
dnf install -y pacemaker pcs corosync

# Podman
dnf install -y podman
Network setup
  • A dedicated network interface between cluster nodes is recommended
  • Allow the DRBD replication port (7789 by default) through the firewall
  • A host NIC for the IPVLAN container network
  • Allow the corosync ports (5404, 5405 UDP)
Ansible control node
  • SSH key access from this web server to every node
  • Ansible installed: pip install ansible
Architecture

This tool configures a 2-node HA cluster. DRBD replicates block storage active/passive, Quadlet lets systemd manage the Podman containers as services, and Pacemaker constrains the containers to run only on the node where DRBD is promoted.

[Node 1] DRBD Primary ← Promoted → Quadlet Container (IPVLAN)
            ↕ DRBD Sync
[Node 2] DRBD Secondary ← Standby
