LINSTOR Deployment experimental

Generates an inventory and playbook that install and initialise a LINSTOR cluster using LINBIT's official Ansible collection (linbit.linstor) and provision DRBD resources on top of it. This app never assembles linstor CLI commands itself — it calls the collection's roles and modules directly (see PLAN.md section D).

On RHEL/AlmaLinux9 the official LINBIT repository is subscription-only, so there is no free package source. The RPM directory below must already contain linstor-*.rpm files built by a separate pipeline (gsdc-linbit-build, outside this repository). The generated playbook installs them locally on each node before handing off to the official collection.

RPM and deployment options
With Pacemaker-managed enabled, the playbook assumes the DRBD resources will be driven by an ocf:linbit:drbd promotable clone from the Pacemaker tab, and adds the prerequisites below. Each of these was observed to fail differently on a real 3-node cluster when missing:
  • auto-promote no — the DRBD default is yes, so the kernel promotes on its own and fights Pacemaker for control of promotion.
  • drbd-selinux — without it the resource agent cannot even create the netlink socket it needs to talk to the kernel.
  • /var/lib/linstor.d relabelled to etc_t — otherwise the resource agent cannot read the .res files LINSTOR writes and fails with "DRBD resource ... not found in configuration file".
