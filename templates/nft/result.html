적용 방법

생성된 파일을 서버에 배포하고 nftables를 재시작합니다.

① 파일 배포
# {{ result.filename }} 파일을 서버에 복사
scp {{ result.filename }} root@<server>:/etc/nftables/

# 또는 직접 작성
tee /etc/nftables/{{ result.filename }} <<'EOF'
(파일 내용 붙여넣기)
EOF
② nftables 설정에 include 추가 /etc/nftables.conf
include "/etc/nftables/{{ result.filename }}"
③ 적용 및 검증
# 문법 검사
nft -c -f /etc/nftables/{{ result.filename }}

# 즉시 적용 (테스트)
nft -f /etc/nftables/{{ result.filename }}

# 영구 적용 (재부팅 후에도 유지)
systemctl reload nftables
# 또는
systemctl restart nftables
④ 규칙 확인
nft list table netdev {{ result.policy.table_name }}
nft list chain netdev {{ result.policy.table_name }} {{ result.policy.chain_name }}
