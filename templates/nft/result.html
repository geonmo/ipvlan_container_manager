How to apply

Deploy the generated file to the server and restart nftables.

1. Deploy the file
# {{ result.filename }} Copy the file to the server
scp {{ result.filename }} root@<server>:/etc/nftables/

# Or create it directly
tee /etc/nftables/{{ result.filename }} <<'EOF'
(paste the file contents)
EOF
2. Add an include to the nftables config /etc/nftables.conf
include "/etc/nftables/{{ result.filename }}"
3. Apply and verify
# Syntax check
nft -c -f /etc/nftables/{{ result.filename }}

# Apply now (test)
nft -f /etc/nftables/{{ result.filename }}

# Apply persistently (survives reboot)
systemctl reload nftables
# or
systemctl restart nftables
4. Check the rules
nft list table netdev {{ result.policy.table_name }}
nft list chain netdev {{ result.policy.table_name }} {{ result.policy.chain_name }}
Deploy with Ansible (same file on every cluster node)
A pod can fail over to any node, so the same file is deployed to the whole cluster rather than to individual nodes. Run: ansible-playbook -i inventory.yml deploy_nftables.yml
