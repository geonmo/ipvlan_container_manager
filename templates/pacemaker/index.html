      DRBD 볼륨을 추가하거나 위 드롭다운에서 선택하세요.
      각 DRBD Promotable Clone 리소스마다 Filesystem 마운트가 연결됩니다. DRBD Primary 승격 → FS 마운트 → 서비스 시작 순서로 자동 제약조건이 생성됩니다.

      group_name: 그룹 이름 (예: grp-myapp), members: 리소스 이름 순서 목록 — Pod를 첫 번째로, after_fs: 선행 FS 리소스 이름

      resource_name: Pacemaker 리소스 이름, systemd_unit: systemd 유닛 이름 (예: myapp.service), resource_type: container | pod | volume

      DRBD Promoted 후 서비스 시작 (Order) + 동일 노드 실행 (Colocation: INFINITY) 규칙을 자동 생성합니다.
      예: [{"id":"ord-1","first":"drbd-r0-clone","first_action":"promote","then":"myapp","then_action":"start","kind":"Mandatory"}]
